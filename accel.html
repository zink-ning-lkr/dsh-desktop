下载加速设置
多线程分段下载桌面端更新
并发 6 段
更新安装包将分成多段同时下载并校验 sha512。段数越多越快,但并发过高可能被 CDN 限流; 文件过小时会自动退化为单段下载。保存后对下一次更新下载生效(进行中的下载不受影响)。
当前有更新下载进行中,新设置将在下次下载时生效。
镜像源可选
镜像目录内放置与 GitHub Release 资产同名的安装包即可 (参考 GitHub 官方镜像/自建仓库的目录结构;版本检查与完整性校验仍走 GitHub 官方)。 镜像失效或拉取失败时,下载会自动回退官方源,不影响更新。
dsh 本体更新npm
本体经 npm 安装,速度受默认源(registry.npmjs.org)影响。网络慢时可切换到国内镜像:
npm config set registry https://registry.npmmirror.com
复制后在终端执行,然后重新「检查 dsh 本体更新」。
改动即时保存到 config.json
